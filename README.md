## 📁 Repository Projects

### 🛢️ [LPG Distribution & Consumer Management System](./LPG%20distrubution%20management%20system/)
A production-ready, full-stack enterprise web platform and operational command hub engineered specifically for authorized LPG distributorship agencies handling over **22,000+ registered domestic and commercial consumers** in the Kanpur Nagar, Kanpur Dehat, and Hamirpur logistics corridors (Agency Code: `UP-KNP-78401`).

- **Architecture**: Modular 4-Tier Enterprise Architecture (Django REST API, AngularJS SPA Frontend, Streamlit Operations Hub, MySQL/SQLite Engine)
- **Backend**: Python 3.13, Django 6.1, Django ORM, Atomic Concurrency (`select_for_update`), 6-digit DAC OTP delivery verification
- **Frontend SPA**: AngularJS 1.8.2 Single-Page Application, Bootstrap 5.3, Bespoke Indian Enterprise Palette (Terracotta `#E2725B`, Deep Saffron `#FF9933`, Turmeric `#FFC000`, Indian Rupee `₹`)
- **Operations Hub**: Streamlit 1.66+ command center with live inventory meters, route dispatch bar charts, and direct refill booking terminal
- **Documentation & Presentation**: Includes comprehensive setup guide, seed script with 300+ consumers, and a 16:9 widescreen Microsoft PowerPoint presentation (`.pptx`) with automated generation script.

For full setup, database configuration, and launch instructions, see [**LPG Distribution Management System README**](./LPG%20distrubution%20management%20system/README.md).
